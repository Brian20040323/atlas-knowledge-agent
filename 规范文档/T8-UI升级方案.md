## 2. 改进方案（分阶段）

### T8-1 · 结构化回答渲染（立即做）

v3 prompt 输出四段式：**制度依据 / 推理分析 / 结论 / 补充说明**。前端应识别并风格化：

```
┌─ 制度依据 ──────────────────────────┐
│ 📋 《差旅报销制度》规定…            │
├─ 推理分析 ──────────────────────────┤
│ 💭 制度将「住宿」作为报销类别…      │
├─ 结论 ──────────────────────────────┤
│ ✅ 民宿住宿费用理论上可报销…        │
├─ 补充说明 ──────────────────────────┤
│ ⚠️ 制度未明确排除民宿，以上为推断…  │
└──────────────────────────────────────┘
```

**方案：** CSS `.answer-section` 类 + JS 自动识别 `**制度依据**` / `**推理分析**` / `**结论**` / `**补充说明**` 标记。

### T8-2 · Trace 查看面板（立即做）

在顶部栏增加 `📊 Trace` 按钮，点击展开最近 10 条运行记录：

```
┌─ Trace 面板 ──────────────────────────────────┐
│ run_abc  ·  local  ·  245ms                    │
│ └─ retrieve_local  42ms  hits=3                │
│ └─ plan  1ms  intent=local                     │
│ └─ react_tools  …                              │
│ └─ llm_synthesize  198ms                       │
│                                                 │
│ run_def  ·  composite  ·  620ms                │
│ └─ composite_search  …                         │
└─────────────────────────────────────────────────┘
```

**方案：** 模态弹窗，从 `GET /api/runs` 拉数据，span 树形展示。

### T8-3 · 系统状态栏（立即做）

顶部栏右侧增加系统状态指示器：
- 🟢 Live / DeepSeek v4-pro | 🟡 Mock 模式 | 🔴 未连接
- 知识库文档数 | 缓存命中率 | P50 延迟

### T8-4 · 暗色模式（15 分钟搞定）

CSS 变量方案，一个 `data-theme="dark"` 切换全部配色。

### T8-5 · 回答反馈（做完上面做）

每条 assistant 消息下方加 👍 👎 按钮，记录到本地存储。

### T8-6 · 评测面板（单独页面，交给 Cursor）

新增 `/eval.html` 页面：显示 126 题通过率、失败详情、重新跑评测按钮。
