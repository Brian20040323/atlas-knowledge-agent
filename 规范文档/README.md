## 铁律（写项目前）

1. **先读 07**，只实现「待办」中标注为下一阶段的项，不顺手加向量/图谱/新炫技模块。  
2. **每改行为必跑** `python scripts/run_eval.py`，结果写入 [eval-baselines/](eval-baselines/)。  
3. **制度类问题**：无库内依据必须明确拒绝，禁止编造；禁止空库自动联网当制度答案（见 02）。  
4. 旧路径 [`docs/`](../docs/) 仅保留重定向，**以本目录为准**。
