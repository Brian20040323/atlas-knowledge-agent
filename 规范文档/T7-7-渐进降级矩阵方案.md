# T7-7 · 渐进降级矩阵方案

> 状态：📋 方案 · 2026-07-21  
> 依据：字节审查 Q3  
> 目标：从单层降级（LLM挂→全mock）升级为多层降级（根据各组件状态组合最优回答）

---

## 1. 痛点

当前降级是「开关式」的：

```python
# 现在：LLM 挂了 → 整段退到 mock
if llm_failed:
    async for event in self._mock_answer(...):  # ← 完全忽略联网/研究结果
        yield event
```

问题：如果 LLM 挂了但 `web_search` 拿到了有效的网页摘要——这些结果全部浪费了。

面试官会问：
> LLM 挂了但联网正常、本地检索正常——你能用联网+本地混合合成吗？还是直接退化到最差路径？

---

## 2. 方案设计

### 2.1 降级矩阵（4 条路径）

| 路径 | LLM | 本地检索 | 联网/研究 | 合成方式 | mode 标记 |
|------|-----|---------|----------|---------|----------|
| P0 全功能 | ✅ | ✅/❌ | ✅/❌ | LLM 综合 | `llm` |
| P1 LLM挂但素材全 | ❌ | ✅ | ✅ | 规则综合（本地+联网混合） | `degraded_rich` |
| P2 LLM挂仅本地 | ❌ | ✅ | ❌ | 规则综合（仅本地） | `degraded_local` |
| P3 LLM挂全空 | ❌ | ❌ | ❌ | 通用拒答 | `degraded_empty` |

### 2.2 核心思路：状态收集 → 路径决策 → 规则合成

```
stream_chat() 执行完毕 → 收集状态
  ├── llm_ok: bool        # LLM 是否正常
  ├── hits: list          # 本地检索结果
  ├── web_hits: list      # 联网检索结果
  ├── research_hits: list # 百科研究结果
  └── plan.intent         # 原始意图

→ 根据状态选择路径
  ├── llm_ok → P0（走原 LLM 路径）
  ├── !llm_ok && (web_hits || research_hits) → P1（混合规则合成）
  ├── !llm_ok && hits → P2（仅本地合成）
  └── !llm_ok && !hits → P3（通用拒答）
```

### 3.3 Step 2: 路径决策

```python
def _select_degradation_path(state: dict) -> str:
    """返回降级路径标识。"""
    llm_ok = state["llm_ok"]
    local_ok = bool(state["local_hits"])
    web_ok = any(
        bool(h.get("hits")) or bool(h.get("results"))
        for h in (state.get("web_hits") or [])
    )
    research_ok = any(
        bool(h.get("hits")) or h.get("learned_count", 0) > 0
        for h in (state.get("research_hits") or [])
    )

    if llm_ok:
        return "P0_full"
    if local_ok or web_ok or research_ok:
        return "P1_rich"
    if local_ok:
        return "P2_local"
    return "P3_empty"
```

### 3.4 Step 3: P1 混合规则合成（`reasoning.py` 新增）

```python
def synthesize_degraded_rich(
    query: str,
    local_hits: list[dict[str, Any]],
    web_hits: list[dict[str, Any]] | None = None,
    research_hits: list[dict[str, Any]] | None = None,
    policy_strict: bool = False,
) -> str:
    """
    P1 降级：LLM 不可用，但有多来源素材。
    规则式综合（本地+联网+研究混合），标注各来源。
    """
    parts: list[str] = []
    has_any = False

    if local_hits:
        has_any = True
        parts.append("### 📋 本地知识库")
        for h in local_hits[:3]:
            title = h.get("title", "未命名")
            body = (h.get("excerpt") or h.get("content") or "")[:200]
            chunk_id = h.get("chunk_id")
            chunk_mark = f"（第{chunk_id+1}段）" if chunk_id is not None and chunk_id >= 0 else ""
            if body:
                parts.append(f"- **《{title}》**{chunk_mark}：{body}")

    if web_hits:
        for wh in web_hits:
            results = wh.get("hits") or wh.get("results") or []
            if results:
                has_any = True
                parts.append("### 🌐 联网检索")
                for r in results[:2]:
                    title = r.get("title", "网页")
                    snippet = (r.get("snippet") or r.get("content") or "")[:200]
                    if snippet:
                        parts.append(f"- **{title}**：{snippet}")

    if research_hits:
        for rh in research_hits:
            results = rh.get("hits") or []
            if results:
                has_any = True
                parts.append("### 📚 百科研究")
                for r in results[:2]:
                    title = r.get("title", "条目")
                    body = (r.get("excerpt") or r.get("content") or "")[:200]
                    if body:
                        parts.append(f"- **{title}**：{body}")

    if not has_any:
        return (
            f"目前无法回答「{query}」。\n\n"
            "系统当前处于降级模式（LLM 不可用），且所有检索来源均为空。\n"
            "建议：稍后重试，或补充本地文档后重新提问。"
        )

    header = f"关于「{query}」：\n\n"
    disclaimer = (
        "\n\n---\n"
        "*⚠️ LLM 服务暂不可用，以上为检索结果直接展示。回答未经过语言模型综合处理，可能存在不连贯之处。*"
    )

    body = "\n\n".join(parts)
    return header + body + disclaimer
```

### 3.5 Step 4: 接入 stream_chat()

```python
# 替换原来的 if llm_failed: _mock_answer(...)
if llm_failed:
    answer_buf = ""
    with trace.span("llm_fallback", reason=llm_error or "llm_error",
                    path=_select_degradation_path(degradation_state)):
        if degradation_state["local_hits"] or degradation_state.get("web_hits"):
            # P1: 有素材 → 混合合成
            reply = synthesize_degraded_rich(
                plan.query,
                local_hits=hits,
                web_hits=degradation_state.get("web_hits"),
                research_hits=degradation_state.get("research_hits"),
                policy_strict=is_policy_question(plan.query),
            )
            mode = "degraded_rich"
        elif hits:
            # P2: 仅本地
            reply = synthesize_knowledge_answer(plan.query, hits, history=messages)
            mode = "degraded_local"
        else:
            # P3: 全空
            reply = f"当前无法回答「{plan.query}」。LLM 服务不可用，且无可用检索结果。请稍后重试。"
            mode = "degraded_empty"

        async for event in self._emit_text(reply):
            if event.get("type") == "token":
                answer_buf += event.get("content") or ""
            yield event
    payload = trace.finish(mode=mode, answer=answer_buf)
    remember_run(payload)
    yield {"type": "trace", "trace": payload}
    yield {"type": "done", "mode": mode, "run_id": trace.run_id}
    return
```

## 4. 验收标准

| 编号 | 场景 | 预期 mode | 回答内容 |
|------|------|----------|---------|
| A | Mock 模式 + 本地有结果 | `mock`（不触发降级） | 正常规则合成 |
| B | LLM 超时 + 本地有结果 + 联网有结果 | `degraded_rich` | 混合本地+联网，标注「LLM暂不可用」 |
| C | LLM 超时 + 仅本地有结果 | `degraded_local` | 仅本地合成 |
| D | LLM 超时 + 全空 | `degraded_empty` | 通用拒答 |
| E | LLM 正常 | `llm` | 走原 LLM 路径，无影响 |

---

## 5. 风险

| 风险 | 缓解 |
|------|------|
| 降级回答质量明显低于 LLM 综合 | 标注「LLM暂不可用」让用户有预期 |
| 降级路径代码复杂度增加 | 状态收集+路径决策只有 ~30 行新代码 |
| 多来源混合时引用混乱 | 分节标题（📋本地/🌐联网/📚百科）区分来源 |

---

- `synthesize_degraded_rich()` 函数保留但不调用（无副作用）
