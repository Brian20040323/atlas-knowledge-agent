# 制度样例包（Atlas 导入测试）

虚构公司：**星辰科技股份有限公司**。仅供本地演示与评测，数字与公司名均为示例。

## 包含文件

| 文件 | 覆盖场景 |
|------|----------|
| `01-差旅与报销管理制度.md` | 住宿标准、交通、餐补、报销材料 |
| `02-考勤与休假管理制度.md` | 年假、事假、加班、打卡 |
| `03-薪酬与福利管理制度.md` | 工资构成、发薪日、绩效、社保公积金 |
| `04-员工奖惩管理制度.md` | 奖励、违纪、虚假报销后果 |
| `05-信息安全与保密管理制度.md` | 账号、外发、U盘、离职交接 |

**故意不提供**：股权激励 / 税率等文档 —— 用于测「诚实拒答」。

## 导入方式（任选）

1. 启动 Atlas：`python run.py` → 打开 http://127.0.0.1:8000 并登录  
2. 左侧「导入文件」或知识库上传，依次上传本目录 5 个 `.md`  
3. 也可在对话里粘贴正文后说「学习知识：……」

建议一次全导入，再按下面问题测路由与引用。

## 建议测试问法

### 应命中制度（local）

- 差旅住宿费标准是多少？一线城市专员能报多少？
- 实习生出差住宿标准？
- 报销差旅要准备哪些材料？时限多久？
- 年假怎么算？入职满一年有几天？
- 工资一般什么时候发？由哪几部分构成？
- U 盘可以拷客户数据带走吗？

### 复合问题（composite）

- 工资怎么算，年假有几天？
- 出差住宿超标怎么处理，假报销会怎样处罚？

### 应拒答 / 未命中（勿编造）

- 公司股权激励税率是多少？
- 期权行权个税怎么算？
- 海外子公司分红政策是什么？

### 闲聊（chitchat，可不检索）

- 你好 / 今天天气怎么样（视实现而定）
